# 3LC Office entertainment device

This folder provides the necessary contents to build the 3LC Office Entertainment device, commonly known as a Rubik's cube.

## Material
To undertake this project, the following materials are required
 - 1 Rubik's cube
 - A pair of scissors
 - A sticker sheet with the printed file

## Files

[placeholder].svg contains vector files necessary to print out stickers.
The file is to be printed in 1 A4 sheet of sticker paper.

## Assembly

1. Start by cutting the individual square out the sheet using the scissors. Cut on the inner edge of the squares.
2. Peel off any sticker your cube may have on it.
3. Stick the new stickers in. Make sure to respect the original orientation and position of the old stickers: this is not an opportunity to solve the cube.
4. Happy solving!
