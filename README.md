### R&D

Each completed experiment done by 3LC Studio will be made available to the public. Each folder represents a project, and contains all the necessary production files, a well as guidance for assembly when required.

Anyone is free to use said projects in any way they see fit. However, 3LC forbids the sale of 3LC brand products. You can use the files for personal use, or rebrand them before commercial use.
